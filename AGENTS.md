# AGENTS.md

## Project scope

This is a personal, exploratory project. Prefer simple solutions that serve the
maintainer's current use cases over compatibility or process complexity that is
not otherwise required.

## Release policy

- Keep the installer verification policy simple. Backward compatibility with
  releases created under older provenance policies is not required.
- Do not add test or approval gating to this repository's release workflow.
  Pre-tag validation and approval, if implemented, belong to tagpr.
